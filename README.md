# Kingdom Wayfinder website

A static, three-page website for GitHub Pages. No build tools or dependencies required. Original Kingdom Guide artwork is included in `assets/` as optimized web images.

## Preview locally

Open `index.html` in a browser. Use the navigation to inspect the Support and Privacy pages.

## Publish with GitHub Pages

1. Create a **public** repository named `kingdom-wayfinder-site` under `Kerriegrl`.
2. Upload the contents of this folder to the repository root (including `assets/`).
3. In repository **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)` and save.
4. Once GitHub reports publication, the site should be available at `https://kerriegrl.github.io/kingdom-wayfinder-site/`.
5. App Store Connect support URL: `https://kerriegrl.github.io/kingdom-wayfinder-site/support.html`
6. App Store Connect privacy policy URL: `https://kerriegrl.github.io/kingdom-wayfinder-site/privacy.html`

Do not enter URLs in App Store Connect until the public pages load successfully. Review privacy claims against the final release build before publication.

## Artwork revision
The supplied original Kingdom artwork is preserved in `assets/original-*`. Optimized WebP versions are used for the live pages. The website is a local preview and is not published. Review the privacy policy before publication.
